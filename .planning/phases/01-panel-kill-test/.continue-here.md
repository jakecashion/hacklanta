## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Stale read before write | A teammate's file was clobbered after a pull landed | blocking | Fetch/status first; Read tool right before Write/Edit |
| Test edits in demo sequence | Probes must not change Sequence 01 | blocking | Clone, test, delete clone; never save |
| Stale relay | Relay started before a relay.js change rejects the new ops | blocking | Compare relay process StartTime with the commit time; ask the user to restart |
| Mixed line endings | `bridge.jsx` is CRLF, JS files are LF; scripted replace on `bridge.jsx` missed | advisory | Normalize `\r\n` to `\n`, write back with the original ending |
| Bash heredoc with JS template strings | A large heredoc with backticks and `${}` broke bash parsing | advisory | Write patch scripts with the Write tool, run them with `node` |
| Background `&` drops `cd` | `cd X && node a & node b` ran `b` in the wrong folder | advisory | Use absolute paths for every command in a background line |
| Assumed frame rate | Demo sequence is 23.976 fps (`timebase` 10,594,584,000 ticks) | advisory | Read `sequence.timebase` |
| `python` in Bash | Windows Store stub, hangs | advisory | Use `node -e` |
