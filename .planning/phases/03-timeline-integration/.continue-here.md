## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Stale read before write | A teammate's file was clobbered earlier after a pull landed | blocking | Fetch/status first; Read tool right before Write/Edit |
| Assumed frame rate | Frame counts reported at 29.97 fps; sequence is 23.976 | blocking | Read `sequence.timebase` and convert ticks to frames |
| Events lost on restart | `app.bind` handlers were gone after a Premiere restart, so hand-edit events were not captured | advisory | Bind again after every Premiere restart before an event probe |
| Shell-quoted ExtendScript | Bash/`node -e` quoting broke JSX strings several times (backslash paths, nested quotes) | advisory | Write JSX/JS files with the Write tool; pass Windows paths with escaped backslashes |
| Hash-compare of exported frames | `exportFramePNG` output is never byte-identical | advisory | Compare pixels (System.Drawing C# helper), not file hashes |
| `python` in Bash | Windows Store stub, hangs | advisory | Use `node -e` |
